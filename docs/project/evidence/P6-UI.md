## Working path

Overview → stored Session Explorer → Investigation → signed Evidence Record →
original-attack Regression. Routes also provide session/job/record lists, settings,
and accurate unavailable Sentinel/Preflight screens. Every primary action calls a
real endpoint, navigates to stored evidence, or explains its disabled state.

One occurrence selection synchronises candidate, stable provenance node, associated
captured event, details and intervention comparison. Event selection updates graph/
details; URL selection survives refresh. Edges are observable relationships, not
proven causes. Hostile input is text; graph and interval values have table alternatives.
Native dialogs contain focus and Escape returns it. CSS honours reduced motion.
Local fonts/icons/assets work offline.

REST snapshots own counters/results. Both job SSE streams use persisted events,
scoped IDs, deduplication, Last-Event-ID and snapshot recovery. No timer increments
a trial count. Interruption/cancellation retain reservations, actual outcomes and
inconclusive states. Pending regression starts clear previous results; refresh
restores source record, contract and configuration.

Mode, evidence, capture/replay coverage and integrity are separate. Local trace-key
verification is not independent record verification. Uploaded-file verification does
not automatically verify the displayed record. Exact backend plan/payload text
preserves 64-bit seeds; downloads preserve original bytes. Governance remains pending.
Signer integrity does not prove truth, external anchoring, human identity or blame.
