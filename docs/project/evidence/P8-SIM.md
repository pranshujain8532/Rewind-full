## Working product path

Preflight remains the fourth accepted product mode. One explicit target identifier,
owned-support-agent-v1, accepts preflight-fixed-v1 only. Arbitrary target URLs, paths,
unknown versions/configurations, real-model modes and nonzero provider budgets are
rejected. Four reviewed cases per surface: clean, export directive, benign imperative,
unknown attachment. Target fixtures never discover credentials or invoke external tools.

Both ticket comments and actual mock-file text run inside the existing non-root,
read-only, no-network, resource-limited container. The file payload is excluded from
the ticket response, then read through the actual owned SDK files.read function and
matched to its inserted model-input occurrence. All effects are private mock outboxes.
Fresh model decisions, observed SDK schemas/reads, attempts, policy events, dispatches
and outcomes use the existing encrypted signed recorder. This is simulator evidence.

Plans freeze target, fixture/configuration versions/digests, seed/repeats, image/probes
and resource limits. Persistent reservations/leases and shared-worker exclusion bound
execution. A reservation and partial source header commit atomically. Timeouts/crashes
retain incomplete outcomes; cancellation stops further starts and keeps actual in-flight
results. Duplicate cancellation is idempotent. No automatic retry/substitution occurs.

The UI reads authoritative snapshots and persisted SSE, shows raw surface/configuration
numerators and valid denominators with explicit invalid/incomplete/unstarted coverage,
and links failures to their actual sessions and idempotent bounded source investigations.
Partial/invalid source replay is refused. Model/configuration/fixture/surface/resource
facts remain visible. A completed job is not a safety certificate: negative controls
can make its evidence status invalid_experiment while its execution is complete.

Unsafe attempts, rule-based policy blocks, harmful mock dispatch and useful work are
separate code-owned facts. No guardrail classifier exists: detection/evasion is Not
measured. No decorative risk percentage. Fixed suite is implemented/verified separately
from evolutionary generation and LLM variations, which are not implemented.
